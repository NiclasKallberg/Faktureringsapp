Det här är ett fakturerings- och kundregisterprogram där man kan ha en databas med sina kunder och skriva fakturor med hjälp av detta.

## 🛠️ Arkitektur & tech-stack

* **Frontend**: ASP.NET Web Forms, HTML5, CSS3, Vanilla JavaScript, jQuery
* **Backend**: C#/.NET Framework
* **Database**: MySQL
